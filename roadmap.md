# Image Journey - Bits to Pixels over the Network

## Project Vision
An interactive educational website that visualizes the complete journey of turning raw binary data into an image and transmitting it over a simulated network.

## Roadmap

### Phase 1: Core Structure & UI (Current)
- [x] Single-page HTML layout
- [x] Binary textarea input
- [x] Presets (black, white, checkerboard, gradient)
- [x] Basic sender / network / receiver 3-column layout
- [x] Responsive dark tech UI with Tailwind

### Phase 2: Binary → Image Encoding
- [ ] Raw 8x8 bitmap rendering from binary
- [ ] PNG format simulation (Signature, IHDR, IDAT chunks)
- [ ] Canvas progressive scanline rendering
- [ ] Support loading small real PNG files

### Phase 3: Network Transmission
- [ ] Animated OSI / TCP-IP layers
- [ ] Packet creation and encapsulation
- [ ] Physical layer (bits on wire / waves)
- [ ] Routing visualization

### Phase 4: Receiver Side
- [ ] Simulated decoding
- [ ] Image reconstruction
- [ ] Side-by-side comparison

### Phase 5: Polish & Education
- [ ] Step-by-step controls
- [ ] Detailed explanations per layer
- [ ] More presets and examples
